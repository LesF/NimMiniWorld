# Nim Mini World - Vehicle Drive & Terrain Elevation
I'm learning Nim by jumping in to some complex code and learning as I go.  This is a small world with a vehicle that can drive around on heightmapped terrain.

Naylib was my choice for 3D graphics, providing another learning path to go down. https://github.com/planetis-m/naylib


### Assets
Initial inspiration came from my previous experience with map creation for some old games, combined with some modelling and CAD work (for 3D printing).  I'm not a mesh wizard, I just like to tinker and see what happens.

Thanks to Kenney for some great assets: https://kenney.nl/
